Sistema de Compras com Desconto

Projeto desenvolvido em **Visualg 3.0.7**, utilizando lógica de programação, estruturas condicionais e estruturas de repetição.

 Objetivo

Simular um sistema de compras que verifica o saldo disponível, calcula descontos progressivos e determina se uma compra pode ser autorizada.

Funcionalidades

- Leitura e validação do saldo disponível.
- Rejeição de saldos negativos.
- Leitura e validação do preço do produto.
- Rejeição de preços iguais ou inferiores a zero.
- Cálculo de descontos progressivos.
- Verificação de saldo suficiente para realizar a compra.
- Cálculo do saldo restante.
- Exibição de valores monetários com duas casas decimais.

 Regras de desconto

 Valor da compra                     Desconto 

Abaixo de R$ 200,00                   0% 
De R$ 200,00 até R$ 499,99            10% 
A partir de R$ 500,00                 15% 

Tecnologias utilizadas

- Visualg 3.0.7
- Portugol
- Lógica de programação

 Como executar

1. Instale o Visualg 3.0.7.
2. Baixe o arquivo `SistemaDeCompraComDesconto.alg`.
3. Abra o arquivo no Visualg.
4. Execute o algoritmo.
5. Informe o saldo disponível e o preço do produto.
6. Observe o desconto aplicado, o resultado da compra e o saldo restante.

 Conceitos praticados

- Variáveis do tipo real.
- Estruturas condicionais `se`, `senao` e `fimse`.
- Estruturas de repetição `enquanto` e `fimenquanto`.
- Operadores relacionais e lógicos.
- Validação de dados.
- Cálculos percentuais.
- Testes de valor-limite.
